# Fiki — 물고기 위키

폰에서 쓰는 개인용 물고기 백과사전. `fikihaveyoueverseenfish/` 폴더가 앱 본체(설치형 웹앱, PWA)다.

- 주소: https://yekimj.github.io/fikikii/fikihaveyoueverseenfish/
- 크롬에서 열고 메뉴 → **홈 화면에 추가**(또는 "앱 설치")를 하면 전체화면 앱처럼 열리고, 한 번 연 뒤에는 와이파이 없이도 열린다.
- 편집 내용과 사진은 **그 폰 안에만** 저장된다 (이 저장소에는 올라가지 않음). 편집 페이지 맨 아래나 써니에게 "백업"이라고 말해서 백업 파일을 받아 둘 것.
- 물고기 정보 출처: [FishBase](https://www.fishbase.se) (CC BY-NC).

파일은 Claude가 만들어 올린다. 틀과 빌드 스크립트는 Claude 프로젝트 "물고기 공부 게임 만들기"에 있다.
